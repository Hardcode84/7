# GFX950 Matmul Profiles

## Repro Preflight

After branch switch or rebase, rebuild every tool used by matmul calibration:

```bash
cmake --build build --target wave-opt wave-translate WavePythonModules -j "$(nproc)"
```

`wave-matmul-calibrate` invokes `build/bin/wave-translate` for HSACO and ISA
generation. Rebuilding only `wave-opt` can leave stale codegen in perf runs.

Large checked runs compute a CPU reference; use `--no-check` for perf sweeps
and keep correctness checks to smaller smoke shapes.

`wave-sim-report` runs are capped to 32 loop trips by default to keep large-K
reports responsive. Pass `--sim-trip-count=-1` when a full-trip simulator
report is required.

Perf ASM goldens for the f16 and MXFP4 profiles are generated by
`test/PerfGolden/test_*.py` through `--emit-asm`. Do not add frozen Wave MLIR
inputs for these profiles.

## Calibration Inputs

Default calibration inputs are random because they match the Gluon tutorial
bench setup: f16 uses random A/B values, and MXFP4 uses random packed FP4
values with random e8m0 scales in `[124, 128)`.

`--all-ones` is historical context and a probe. It fills f16/bf16 A/B with
`1.0`, MXFP4 A/B with packed `0x22`, and MXFP4 scales with `0x7f`. Do not
compare all-ones results directly against random-input runs.

## Denorm Probe

Input-mode rows used the same scheduled HSACO; only runner-owned input buffers
changed. Denorm rows reassembled the same ISA with only
`.amdhsa_float_denorm_mode_32` and/or `.amdhsa_float_denorm_mode_16_64`
changed from `3` to `0`. `3` preserves source/destination denorms, and `0`
flushes them.

| Kernel | Input | Denorm 32 | Denorm 16/64 | Time us | TFLOP/s |
|---|---|---:|---:|---:|---:|
| f16 K=8192 | random | 3 | 3 | 210.874 | 1303.5 |
| f16 K=8192 | all-ones | 3 | 3 | 147.369 | 1865.2 |
| f16 K=8192 | random | 0 | 0 | 147.450 | 1864.2 |
| f16 K=8192 | random | 0 | 3 | 147.288 | 1866.3 |
| f16 K=8192 | random | 3 | 0 | 147.591 | 1862.4 |
| MXFP4 K=32768 | random | 3 | 3 | 250.964 | 4381.2 |
| MXFP4 K=32768 | all-ones | 3 | 3 | 211.077 | 5209.1 |
| MXFP4 K=32768 | random | 0 | 0 | 251.472 | 4372.3 |

f16 random slowdown is FP-mode-sensitive, but defaulting to flush-denorm needs
a correctness policy. MXFP4 random slowdown is not explained by denorm mode;
all-ones only proves the 5000+ band is input-distribution dependent.

## `gfx950-f16-256x256-16wave`

Recommended f16 GEMM perf baseline for 4096x4096xK:

```text
bm=4
bn=4
wave_m_tiles=4
wave_n_tiles=4
wave_k_tiles=1
use_buffer=true
use_dma_lds=true
matrix_intrinsic=mfma_gfx950
input_type=f16
output_type=f16
cta_swizzle_xcds=8
cta_group_m=4
```

This is a 256x256 CTA with 16 waves and 32-wide MFMA K steps. Example:

```bash
python tools/wave-matmul-calibrate/wave-matmul-calibrate.py \
  --chip=gfx950 --kernel-profile=gfx950-f16-256x256-16wave \
  --m=4096 --n=4096 --k=4096 \
  --variants=scheduled --iters=500 --warmup=20 --repeats=3 --no-check
```

## `gfx950-mxfp4-256x256-8wave`

Recommended MXFP4 GEMM perf baseline for 4096x4096xK:

```text
bm=4
bn=2
wave_m_tiles=4
wave_n_tiles=8
wave_k_tiles=2
use_buffer=true
use_dma_lds=true
matrix_intrinsic=mfma_gfx950
input_type=mxfp4
output_type=f16
cta_swizzle_xcds=8
cta_group_m=4
```

This is a 256x256 CTA with 8 waves and two 128-wide MFMA K steps per
loop body. Example:

```bash
python tools/wave-matmul-calibrate/wave-matmul-calibrate.py \
  --chip=gfx950 --kernel-profile=gfx950-mxfp4-256x256-8wave \
  --m=4096 --n=4096 --k=32768 \
  --variants=scheduled --iters=200 --warmup=20 --repeats=3 --no-check
```

## `gfx950-mxfp4-256x256-4wave`

Lower-occupancy MXFP4 GEMM profile for 4096x4096xK:

```text
bm=2
bn=2
wave_m_tiles=8
wave_n_tiles=8
wave_k_tiles=1
target_waves=1
use_buffer=true
use_dma_lds=true
matrix_intrinsic=mfma_gfx950
input_type=mxfp4
output_type=f16
cta_swizzle_xcds=8
cta_group_m=4
```

This is a 256x256 CTA with 4 waves and one 128-wide MFMA K step per loop
body. Example:

```bash
python tools/wave-matmul-calibrate/wave-matmul-calibrate.py \
  --chip=gfx950 --kernel-profile=gfx950-mxfp4-256x256-4wave \
  --m=4096 --n=4096 --k=32768 \
  --variants=scheduled --iters=100 --warmup=10 --repeats=3 --no-check
```
